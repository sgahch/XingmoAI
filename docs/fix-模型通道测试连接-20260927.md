# 修复：模型通道「测试连接并列出模型」报“演示模式或未配置”

日期：2026-09-27

## 现象

控制台「模型通道配置」页填好 Base URL / API Key / 模型名后，点「测试连接并列出模型」仍提示：

> 当前为演示模式或未配置上游通道，无法拉取真实模型列表。请先在模型通道配置中填写 Base URL、API Key 与模型名称并保存。

但管理员账号（admin）能正常列出 12 个模型，新注册的 `ynchen` 账号不行。

## 根因

1. **半配置陷阱（核心 bug）**：`auth_register` 在注册时把全局通道的 `Base URL` 和 `模型名` 写进了用户自己的 `user_settings` 行，却把 `API Key` 置空。结果该账号的页面显示“自定义通道（已填好 URL/模型）”，但服务端因为缺 Key 永远连不上上游——且提示语把“缺 Key”误报成了“演示模式或未配置”。
2. **测试按钮只读已保存配置**：`/api/models/fetch` 只用服务端已存配置，忽略表单里刚填的值。用户填完表单直接点测试（还没点保存），服务端读到的是旧/空配置，所以报错，进一步造成“明明填了却说没填”的错觉。
3. **错误信息不精确**：整段只有一句“演示模式或未配置”，无法区分到底是演示模式、缺 URL、缺 Key 还是缺模型名。

## 修复

- `server/app.py`
  - 注册新账号时不再把全局的 Base URL/模型名写进用户行（改为 demo + 空），由 `upstream_config` 在用户行真正未配置时透明回退到全局默认通道（含 Key）。彻底消除“半配置”状态。
  - 启动时对已有的“半配置”历史行做一次数据修复（模式非 demo、但 Key 为空且 Base URL/模型名恰好等于全局值 → 重置为 demo + 空）。
  - `/api/models/fetch` 改为支持 POST：以**表单当前值**为主，Key 留空则沿用已保存的那把；返回精确 `reason`：`demo_mode` / `incomplete(缺失字段)` / `upstream(含上游 HTTP 状态码与 401/403 提示)`。
  - 新增 `normalize_base_url`：用户把 `.../v1/chat/completions` 这类尾巴粘进 Base URL 时自动收敛，避免路径重复。
  - `settings` 接口新增 `channel_source`（global / user），前端区分“继承全局默认通道”与“本账号配置”。
- `web/app.js`
  - 「测试连接并列出模型」按钮改为把表单内容 POST 给后端，填完即测，不必先保存。
  - 顶部标签显示当前生效通道来源；按钮上方加一句说明“API Key 留空则沿用已保存的那把；保存后才对聊天与对外 API 生效”。
  - `api()` 现在把后端返回的错误信息透出（如“自定义通道需要填写 Base URL、API Key 和模型名称”），不再吞成“请求未完成”。

## 验证（已在本机跑通）

- `ynchen` 账号 `user_settings` 修复为 demo + 空，页面现在正确回退到全局默认通道。
- `GET /api/models/fetch`（用全局通道）：返回 12 个模型，`ok: true`。
- `POST /api/models/fetch`（用表单值，含 Key）：返回 12 个模型，`ok: true`。
- 演示模式 → 精确提示“运行模式是演示模式…请切换为自定义模型通道”。
- 错误 Key → `上游返回 HTTP 401（API Key 无效、过期或无权访问）：Invalid token ...`。
- Base URL 误填 `.../v1/chat/completions` 尾巴 → 自动归一化后仍成功。
- `POST /api/chat` 走真实上游，返回实模型回复（非模拟）。

## 备注 / 后续

- 全局 `settings` 表以**明文**保存 Agnes API Key（`agnes-ai.com` 官方 key）。后续若要给真实客户演示，建议把 Key 从库里迁到部署服务器私有 `.env`，控制台只保留哈希/占位。
- 当前 `save_settings` 要求自定义通道必须有 Key。若客户物理机本地 7B 模型**无需鉴权**，需放宽该校验（连同 `upstream_request` / `proxy_upstream_models` 的 Key 必填判断）。需要的话再改。
- 服务已用 `run_in_background` 重启在 `http://127.0.0.1:5178`，会话结束后可用 `.\start-demo.ps1` 自行重启。
