# 手机端「侧边栏消失」修复 — 移动端响应式适配

日期：2026-09-27
涉及文件：`web/styles.css`、`web/app.js`

## 现象

手机访问（390px 宽）聊天页时：

- 左侧对话栏完全不见，只剩「有什么我能帮你的吗？」占满全屏；
- 左上角那个 `||` 按钮点了没反应；
- 于是手机端**没有任何入口**能新建对话、切换历史会话、进控制台或退出登录，只有输入框可用。

## 根因

1. `web/styles.css` 中 `@media (max-width:760px)` 里有一行 `.doubao-sidebar { display:none; }` —— 窄屏时把整个侧栏直接砍掉，且没有提供任何替代入口（抽屉 / 底栏都没做）。
2. `web/app.js` 中 `.chat-topline` 的收起按钮 `<button class="collapse-button">||</button>` **没有绑定任何事件**，纯装饰。
3. 同类问题也存在于控制台页：`@media (max-width:900px)` 里 `.console-nav { display:none; }`，手机上进控制台后无法切换到「企业知识库 / API 密钥 / 对话记录 / 模型通道」，只能停在概览页。

## 改动

### 1. 聊天页：侧栏改为「抽屉 + 遮罩」（`styles.css` 760px 断点）

- `.doubao-sidebar` 在窄屏改为 `position:fixed`（宽 `min(282px,84vw)`，`z-index:40`），默认 `transform:translateX(-102%)` 移出屏外；
- `.chat-shell.sidebar-open .doubao-sidebar { transform:none; }` 滑入；
- 新增 `.sidebar-scrim` 遮罩（`z-index:35`），点遮罩关闭抽屉；
- 窄屏下 `.chat-shell` / `.doubao-main` 用 `height:100vh; height:100dvh`，把滚动收敛到 `.doubao-scroll` 内部，输入框固定在底部（不再整页滚动）；
- 抽屉与输入框加上 `env(safe-area-inset-*)`，避开刘海屏和底部横条；
- 推荐问题按钮在窄屏改为整行宽度，避免长短不一。

### 2. 聊天页：菜单按钮真正可用（`app.js`）

- `||` 换成内联 SVG 汉堡图标（`const menuIcon`）；
- 按钮改为 `data-action="toggle-sidebar"`：**窄屏**切换抽屉（`sidebar-open`），**宽屏**切换侧栏折叠（`sidebar-collapsed`），一套按钮两种语义；
- 新增 `isMobile()` / `setSidebar()` / `closeSidebar()`；
- 点击历史会话（同页刷新、不重建 DOM 的分支）时主动关抽屉，避免点完还挡着内容。

### 3. 控制台页：侧栏改为顶部横向标签（`styles.css` 900px 断点）

`.console-nav` 不再 `display:none`，改为 `display:flex` + `overflow-x:auto` 的胶囊标签条，`position:sticky; top:68px` 吸在顶栏下方，横向可滑。

### 4. 顶栏与其它窄屏细节

- 顶栏：隐藏 `.user-name`、收紧 padding/gap、缩小 logo 与头像，避免 375px 下被挤爆；
- `.metrics` 在 ≤420px 变单列；`.metric-value` 缩到 23px；
- `.endpoint` 允许换行、URL `word-break:break-all`；
- 登录卡在窄屏收紧内边距。

## 断点矩阵

| 视口宽度 | 聊天页侧栏 | 控制台导航 |
| --- | --- | --- |
| > 900px | 固定常驻 242px，可点按钮折叠 | 左侧竖排 230px |
| 760–900px | 固定常驻 242px | 顶部横向标签条 |
| ≤ 760px | 抽屉式（默认移出屏外，点汉堡滑出 + 遮罩） | 顶部横向标签条 |

## 验证

自检页（纯静态，绕过登录与后端）与截图放在 `docs/responsive-check/`：

- `mobile-check.html?s=closed` — 手机端侧栏收起
- `mobile-check.html?s=open` — 抽屉展开（含遮罩）
- `mobile-check.html?s=open&many=1` — 历史对话很多时，底部账号区仍固定可见
- `mobile-check.html?s=collapsed` — 桌面端侧栏折叠
- `console-check.html` — 控制台页横向标签
- 加 `&probe=1` 会在页面底部打印实际视口与元素尺寸（调试用）
- `shots.html` 用 390px 宽的 iframe 并排渲染多个状态，便于一次性截图比对
- `js-behavior-check.html` — 用桩 `fetch` 直接进入聊天页，自动点击汉堡/遮罩/历史会话并把结果写进 `document.title`；`js-behavior-mobile.html` 把它套在 390px 的 iframe 里跑（结果通过 postMessage 回传），配合 `--dump-dom` 即可拿到 JS 逻辑的断言结果：

  ```
  移动端(inner=390): sidebar pos=fixed | click1 open=true collapsed=false | click2 open=false | scrimClick beforeOpen=true afterOpen=false  → 全通过
  桌面端(inner=1484): sidebar pos=static | click1 collapsed=true | click2 collapsed=false | 遮罩不影响  → 全通过
  ```

截图：`mobile-4-states.png`（手机四状态）、`desktop-collapsed.png`（桌面折叠态）。

## 生效方式

只改了 `web/styles.css` 与 `web/app.js` 两个静态文件，**无需重启服务**。手机上需清掉微信/浏览器缓存后重新打开（微信内置浏览器缓存较顽固，可在链接后加个 `?v=2` 之类的参数强制刷新）。
